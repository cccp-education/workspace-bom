== 2. Trois défauts du cache corrigés (révélés par la mesure)

. **Clé de cache collisionnée** : la clé glissante n'utilisait que
  `strategy.job-index`, toujours `0` pour les jobs **hors matrice** (garde,
  coverage, N0) → trois jobs se disputaient la même clé et les sauvegardes
  étaient refusées (« another job may be creating this cache »). `github.job`
  ajouté à la clé ; le préfixe `restore-keys` assure toujours le partage.
. **SIGPIPE** : le smoke Ollama faisait `ollama run … | head -5` sous
  `pipefail` → sortie tronquée = exit 141 = job rouge. Le flux n'est plus tronqué.
. **Propriété du store de modèles** : le conteneur écrit dans le store monté
  **en root**, y compris des métadonnées *après* le `pull` ; `actions/cache`
  échouait au `tar` (« Permission denied ») et le modèle était **re-téléchargé**
  à chaque run. Correctif : arrêter le conteneur + `chown` du store **avant** le
  post-step de cache.
