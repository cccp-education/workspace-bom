== 2. Constat P0 — le job `N0 · contracts` était un **faux vert**

Lecture du run `41340247377` (job `N0 · contracts`) :

----
PlatformCatalogAlignmentTest > toml agent contracts versions aligned … FAILED
    expected: <0.0.3> but was: <0.0.4>
> Task :test FAILED
BUILD FAILED in 3m 3s          ← agent-contracts
… et pourtant : job = success
----

Cause racine dans `.github/workflows/test.yml` :

[source,bash]
----
| xargs -I{} -P 5 bash -c '
    echo "::group::{} check"
    ( cd "{}" && ./gradlew check --no-daemon --console=plain )
    echo "::endgroup::"        # ← dernière commande : le shell sort TOUJOURS 0
  '
----

La dernière commande du `bash -c` est un `echo` : le sous-shell retourne `0` même
quand `./gradlew check` échoue, `xargs` voit un succès, le step (et le job) sont
**verts**. Preuve du mécanisme (shell, local) :

----
bash -c '( false ); echo end'            → exit 0   (ancien : masque)
bash -c 'set -eo pipefail; ( false ); …' → exit 1   (nouveau : propage)
----

**Portée** : le gate N0 (« 10 builds, 5 concurrent ») était aveugle depuis son
introduction ; il masquait exactement **un** échec réel (la garde catalogue, cassée
en S-331/S-332 : `97cb4a8` a bumpé la garde `workspace-bom` mais pas la ligne
`agent-contracts`, puis `cad127a`/l'adoption du contrat 0.0.4 a laissé la garde à 0.0.3).
