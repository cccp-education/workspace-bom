== Fix-0 — Déblocage baseline (préalable, hors EPIC)

Le build BOM était ROUGE à l'ouverture. 4 causes traitées :

. *Conflit classpath Gradle 9.6.1* — le Gradle embarqué épingle
  `kotlin-stdlib {strictly 2.3.21}` + `annotations {strictly 13.0}` sur le
  classpath buildscript des consommateurs, en conflit avec les constraints
  platform workspace-bom (2.4.10 / 26.0.2-1) tirées transitivement via
  bakery-plugin → document-plugin → plantuml-plugin → workspace-bom.
  Fix : block `buildscript { configurations.all { resolutionStrategy.force(...) } }`
  sur les racines bakery-gradle et runner-gradle (pattern readme-plugin/CNV-12.2).
. *Bug codebase 0.0.11* — `CodebaseOcrExtension.ocrEngine: Provider<OcrEngine>`
  décoré impossible par Gradle (Provider brut non instanciable dans une
  extension). Propriété morte (zéro consommateur/test/wiring) → supprimée +
  import Provider retiré. mavenLocal 0.0.11 re-publié.
. *runAllTests baseline pourrie* — racines consommateurs sans tâche `check`
  (capsule, codebase, codex, graphify, hyperframes, readme — pattern article
  0124) + jhipster (tests avec plugin ID périmé `com.cheroliv.jhipster.persistence`)
  + plantuml (plugin appliqué sans version/alias). Liste restreinte à 5
  boroughs dont le check est vert (api-key-pool, bakery, dashboard, planner,
  slider) — dettes documentées en commentaire du build.
. *WIP dashboard-gradle cassé* — plugin nmcp déclaré dans `pluginManagement.plugins`
  (au lieu du block `plugins` settings) + `com.gradleup.nmcp` sur la racine
  project → scripts compilation error. Corrigé (settings plugins block +
  retrait nmcp racine).
