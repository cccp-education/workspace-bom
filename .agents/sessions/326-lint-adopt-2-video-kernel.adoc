== 3. Défaut réel révélé par l'adoption

`video-kernel-plugin/build.gradle.kts` : `kotlin.jvmToolchain(JavaVersion.VERSION_25.ordinal)`.
L'ordinal de `VERSION_25` vaut **24** (l'énumération commence à `VERSION_1_1`,
donc décale de 1) : le noyau N1 était **compilé pour JVM 24** alors que tout le
workspace cible 25 (le poste local a un JDK 24 installé via SDKMAN, ce qui masquait
le problème ; le CI le téléchargeait via foojay). Corrigé en `jvmToolchain(25)`
(piège déjà inscrit au PROMPT_REPRISE depuis S-317). Build local vert avec le JDK 25.
