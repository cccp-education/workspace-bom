== Enseignement — propagation amont = prérequis *de fait* de l'aval

Le **premier** upload Central de `hyperframes-plugin 0.0.9` a été **rejeté** :
`Dependency version information is missing for … kotlin-stdlib-jdk8 /
jackson-databind / jackson-module-kotlin`. Cause : le POM 0.0.9 importe
`workspace-bom:0.0.99`, **pas encore propagé** sur repo1 → Central ne peut pas
résoudre les contraintes de version. Correctif : publier MEMPHIS, attendre
`repo1 …/workspace-bom/0.0.99/workspace-bom-0.0.99.pom` **HTTP 200**, puis
republier hyperframes → succès. Côté CI consommateur, ce délai est également la
raison d'un échec transient possible si le build précède la propagation.
