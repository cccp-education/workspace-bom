== 1. Mission

Deuxième vague de `MEM-CI-GATE-2` (BACKLOG) : `2.4` — `set -euo pipefail` sur les
4 steps d'installation de `capsule-gradle` et les steps restants (`edster` ×4,
`bakery` website). Chaque dépôt = un correctif minimal + la preuve CI **de son**
dépôt (aucun test local, aucun code applicatif touché).

== 2. `capsule` (commit `545f3cb`) — 4 steps

3 blocs dans `full-tests.yml` (matrices BDD / functional / integration) + 1 dans
`cucumber-full.yml` : `sudo apt-get update` puis `sudo apt-get install -y ffmpeg
espeak espeak-data`. Sans errexit, seul l'`install` décidait : un `update` en échec
(ou un dépôt indisponible) était masqué.

* `set -euo pipefail` ajouté aux 4 blocs ; YAML valide (`ruby -ryaml`) ; audit R1 vide.
* **Preuve** : le workflow ignore `.github/**` en `paths-ignore` (un changement
  workflow-only ne déclenche rien — c'est documenté dans le fichier, qui expose
  `workflow_dispatch` pour cela). Dispatch manuel → **run `41372348607` ✅ 25/25
  jobs**, et le step « Install ffmpeg + espeak » est **SUCCESS 25 fois**.

== 3. `bakery` (commit `34258b7e`) — website

`website.yml` : garde `SITE_YML` → `printf > site.yml` → `./gradlew publishSite`.
L'écriture pouvait échouer (permissions/disque) sans que le step échoue.
`set -euo pipefail` ajouté.

* Preuve : push → **`Test` `41372235984` ✅**, **`Publish website` `41372236161` ✅**
  (le déploiement réel a tourné avec errexit).

== 4. `edster` (commit `a143fb7`) — template versionné uniquement

Deux blocs : `chmod +x gradlew` + `npm run ci:backend:test` ; deux dérivations de
tag + `./gradlew jib …`. `set -euo pipefail` sur les deux.

* **Découverte** : dans ce clone, **`/.github/` est gitignoré**
  (`.git/info/exclude:36`) — le finding `edster/.github/workflows/main.yml` de
  l'audit S-338 portait donc sur une **copie locale non versionnée**. Seul
  `__codebase__/.github/workflows/main.yml` (template JHipster, tracké) est dans
  le dépôt : c'est lui qui a été corrigé (et il est identique à la copie locale).
* `edster` n'a **aucun workflow sur GitHub** (le `.github/` local est exclu) : pas
  de preuve CI possible — preuve statique (YAML + audit) et le hook `lint-staged`
  du dépôt a rejoué `prettier` sur le fichier.
