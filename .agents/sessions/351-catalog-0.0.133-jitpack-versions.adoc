== Dette / note

* **Plateforme BOM** : un consommateur ne peut pas importer le BOM **JitPack**
  comme `platform(...)` — la réécriture POM de JitPack transforme
  `<dependencyManagement>` en `<dependencies>` et aucun `.module` n'est servi.
  Hyperframes conserve donc la plateforme Central `0.0.115` (dernière publiée) ;
  ce n'est pas une incohérence de version mais une limite du canal.
* **Pin `v0.0.133`** : la garde cross-borough `verifyCrossBoroughPins` ne voit
  pas les pins préfixés `v` (regex `workspace-(bom|catalog):[0-9]…`) — angle
  mort connu, à corriger si un jour JitPack sert aussi la forme sans `v`.
* `capsule-plugin 0.0.21` / `conventions-plugin 0.0.16` ne sont **pas** sur
  Central : un consommateur Central-only ne les résout pas — cohérent avec la
  politique JitPack jusqu'au reset.
