Deux précautions :

* `deploy-i18n-site` : `ls … | head -5` rejouait le piège **SIGPIPE** (S-318/S-339) —
  sous `pipefail`, `head` ferme le tube et `ls` sort en 141 → déploiement sain en
  échec. Corrigé par redirection (`> "$RUNNER_TEMP/lang-files.txt"`) puis `head`.
* Le script conserve ses **2 dégradations voulues** (S-049) : `i18n/<lang>`
  absent et variante non déployable → `continue` explicite, aucun échec toléré.

**Finding supplémentaire découvert par le nouvel outil** (§3) :
`translate-i18n-content.yml:63` — `curl -fsSL … | sh` retourne le statut de `sh`
qui lit une entrée vide et **sort 0** quand le téléchargement échoue → Ollama
jamais installé, silencieusement. Corrigé par `set -euo pipefail` (et la règle
« zéro Python » rend le `curl | sh` inévitable ici, mais il est désormais sûr).

== 3. `2.5` — décision : pas de port, un seul audit exécutable

*Constat* : `office` n'a **pas** de build JVM testable (racine `group = "com.cheroliv"`,
aucune tâche de test) ; `capsule`/`magic-stick` ont leur propre CI. Répliquer
`CiShellAudit` dans chaque dépôt serait un **split-brain** (2ᵉ implémentation) et un
coût d'infrastructure disproportionné pour un linter de workflow.

*Décision (autorité pilote)* :

. **Une seule implémentation**, dans `agent-contracts` (domaine pur testé).
. **Exemption fine de R2** : un échec toléré **par item** (boucle de résilience)
   n'est pas un gate masqué, mais la commande seule ne permet pas de trancher →
   marqueur explicite `# ci-shell:allow-swallow` sur la commande (revu en diff).
   Deux tests unitaires épinglent avec/sans marqueur.
. **Exécution à la demande sur tout le workspace** : tâche Gradle
   `ciShellGatesReport` (JavaExec sur le domaine testé, zéro duplication) :

[source,bash]
----
cd agent-contracts
./gradlew ciShellGatesReport -PciRoot=/home/cheroliv/workspace
# ciShellGates: 68 fichier(s) CI audité(s) sous /home/cheroliv/workspace
# ciShellGates: 0 finding(s)
----

. La garde `CiExitCodeGuardTest` reste dans `check` (dépôt seul, prouvé en CI) ;
   le rapport workspace reste **hors** `check` (il exige les dépôts voisins).
