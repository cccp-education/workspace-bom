== Mission

graphify (2 → 3 → 1), dont l'item 3 est la publication Central
`graphify-plugin:0.0.4`. Or la version propre des boroughs est *dérivée du

== Découverte — baseline MEMPHIS rouge à HEAD

`./gradlew test --tests 'contracts.catalog.*'` depuis `agent-contracts/` a
révélé 2 échecs *préexistants* (jamais réalignés) :

[cols="2,3", options="header"]
|===
| Garde | Dérive
| `PlatformCatalogAlignmentTest.workspace-bom` | épinglée `0.0.36` vs toml `0.0.43`
| `PlatformCatalogAlignmentTest.i18n-contracts` | épinglée `0.0.2` vs toml `0.0.4` (dérive S-217 LANG-22)
|===

Les deux sont réalignées dans le même commit que le bump (piège #10).

*Constat de gouvernance* : la baseline MEMPHIS était rouge depuis S-217. Ni la
garde `workspace-bom` (dérive depuis au moins 0.0.43) ni la garde
`i18n-contracts` (dérive S-217) n'ont été détectées — signe que
`contracts.catalog.*` n'est pas systématiquement lancé en clôture de session
MEMPHIS.
