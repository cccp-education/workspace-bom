== 4. Découvertes / pièges S-027

. *nmcp collision deployment* : 2 uploads successifs de la même coordonnée
  → le 2e échoue tant que le 1er est en course ("currently being published in
  another deployment"). Le statut API `publisher/status` peut renvoyer HTTP 500
  pendant la course — ne pas re-tenter immédiatement, attendre et vérifier repo1.
. *Init scripts Gradle* : les accesseurs `ws.*` générés ne sont pas visibles
  dans les init scripts (extension `VersionCatalogsExtension` non résolvable
  sur le projet racine d'un init script) — preuve via settings consommateur réel.
. *Filtrage 2 suites Cucumber dans un même test source set* : la system
  property `cucumber.filter.tags` prime sur `FILTER_TAGS_PROPERTY_NAME` du
  runner — permet 2 runners (glue différentes) coexistants sans source set séparé.
. *Bakery flaky cucumber* : familles i18n-delta/dns/jbake-native échouent
  de façon variable (6 vs 7 FAIL S-026) selon l'ordre des forks — dette
  préexistante, à traiter dans un EPIC bakery dédié (pas MEMPHIS).
