== Objectif

Faire passer le **wall-clock cross-borough** de `workspace-bom` **sous 5 min**
(baseline S-298 : **5m34s**, run `38772146984`). Deux leviers autorisés : rééquilibrer

== Rééquilibrage functional — tenté puis REVERTÉ (mesuré non concluant)

Un rééquilibrage complet des 6 shards functional (28 classes repackées en bins de
somme ≈ 238-246, d'après la mesure par classe du run `38772146984`) a été poussé
(commit `ced3d5a7`) puis **mesuré** : `functional-shard-A` (Arch + InjectLangSwitch
+ TranslateI18nClientOllama) **explose** (257s puis 226s) — le bin nouvellement
constitué est systématiquement le plus long. Les durées par classe sont
**extrêmement instables** d'un run à l'autre (ex. `TreeBakeFunctionalTest` 50s →
3,6s ; `TranslateI18nClientOllamaConfigFunctionalTest` 11,8s → 66,7s) : la
contention TestKit entre classes co-planifiées est **imprévisible** (pairwise,
non modélisable par la somme). La partition S-259 (connue-bonne) est **restaurée**
(commit `b951b91e`). La partition est donc un tirage : on ne la touche pas sans
preuve.

== Leçons

. **Un `-x` incomplet est invisible mais coûteux.** Le job de fusion kover
   exécutait la suite E2E Playwright (35s) sans raison — un test « fantôme » dans
   le sens inverse : une tâche non voulue qui **tourne**. Toujours exclure
   **toutes** les tâches `Test` d'un job de fusion, en miroir du job natif du
   borough.
. **Le pool de runners est une ressource finie.** À 22 jobs pour 21 slots, un job
   est retardé et **devient** le chemin critique. Fusionner le job le plus court
   (nodeTest, sans `.ic`) dans un job voisin supprime la file à coût quasi nul.
. **Le rééquilibrage de shards TestKit est un tirage.** Les durées par classe
   varient d'un facteur ~5 entre runs ; la contention entre classes co-planifiées
   est pairwise et non modélisable par la somme. La partition validée S-259 est
   conservée ; toute modification doit être mesurée, pas déduite.
. La variance infra (±50s/job, pénurie de runners) est le facteur dominant de la
   marge ; la marge acquise (4m56s vs 5m00) absorbe une part de cette variance.
