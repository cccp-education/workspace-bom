=== Types purs (`contracts.plantuml`, zéro Gradle/PlantUML/LLM)

* `PlantUmlBlock` — value object (raw + borrowedVocabulary) + `labels()`
  (quoted labels hors identifiants techniques `Foo.Bar` + directives non quotées
  `title`/`header`/`footer`/`caption`) + `hasBorrowedVocabulary()` +
  `hasTranslatableLabels()`. Extrait de `document.translation.plantuml.PlantUmlBlock`.
* `PlantUmlStrategy` — enum **unique** `TRANSLATE`/`BORROW`/`PRESERVE` (D4) :
  remplace les deux vocabulaires divergents (`document.PlantUmlStrategy` vs
  `plantuml.boundary.TranslationStrategy`).
* `PlantUmlClassifier` — classe pure (ex-`document.…PlantUmlClassifier`) :
  BORROW > TRANSLATE > PRESERVE.
* `SyntaxValidationResult` — sealed (Valid/Invalid) extrait de
  `plantuml.validation` (anticipé par le BACKLOG plantuml).
* `PlantUmlSyntaxValidator` — fun interface (ex-`document.…PlantUmlSyntaxValidator`),
  impl à venir côté plantuml (wrappe le parser natif).
* `PlantUmlTranslationRequest` / `PlantUmlTranslationPort` /
  `PlantUmlTranslationOutcome` — le **port unique** de traduction du bloc (D1/D3) ;
  l'outcome `Preserved` empêche tout fallback FR silencieux marqué traduit.
