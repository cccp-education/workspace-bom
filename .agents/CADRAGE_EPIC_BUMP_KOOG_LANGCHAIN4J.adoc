== Verdict d'analyse (S-228)

* **koog 1.0.0 → 1.2.0** : **faible risque**. Graphe koog figé depuis EPIC L
  (pattern `AIAgentGraphStrategy`/`strategy<DeckState, DeckState>`), JDK 17+,
  Kotlin 2.2.0+ — codebase/planner/capsule sur Kotlin 2.4.10, compatibles.
  Bénéfice : fixes + stabilité depuis août.
* **langchain4j 1.16.3 → 1.20.0** : **moyen risque**, bump « tout-ou-rien ».
  `AllMiniLmL6V2EmbeddingModel` (pgvector embeddings) et le store pgvector
  vivent sur la **ligne beta** (`langchain4j-pgvector` + modules embarqués
  `langchain4j-embeddings`) → en cas de bump, les deux lignes (stable +
  beta) montent **ensemble** (1.20.0 + 1.20.0-beta30). Un écart stable/beta
  incohérent casse la résolution classpath.
* Consommateurs impactés : `codebase` (N1 — socle, store pgvector, LlmBuildService,
  OllamaChatModel), puis `slider`, `capsule`, `planner`, `plantuml`, `document`,
  `codex` (N2). Les contrats N0 (`agent-contracts`, `llm-pool-contracts`,
  `runtime-contracts`, `ocr-contracts`) sont **zéro dépendance** (Tier 0) —
  non impactés.
