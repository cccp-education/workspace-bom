== Objet

Le compilateur Kotlin émet des avertissements qui, non traités, deviennent du bruit
permanent : `npm`-style « on ne lit plus la sortie », warnings qui masquent une vraie
régression (cast `unchecked`, `is` toujours vrai = code mort), et dette qui grossit
avec chaque session. L'objectif est **zéro warning** par dépôt, **sans jamais
supprimer l'information** (`@Suppress`, `-nowarn`, baseline interdits).

== 1. Mesure (S-329, `--rerun-tasks --no-build-cache`)

*Piège méthodologique découvert* : `--rerun-tasks` **seul** peut restaurer les sorties
de test depuis le *build cache* et **masquer** les diagnostics. L'inventaire fiable
est `--rerun-tasks --no-build-cache` (codebase : 4 warnings visibles au lieu de 39).

== 2. Politique (à appliquer à chaque dépôt)

. **Interdits** : `@Suppress("DEPRECATION")` généralisé, `-nowarn`,
   `allWarningsAsErrors` avant propreté, baseline de warnings. Un `@Suppress`
   ponctuel n'est admis que si le warning est **faux** (prouvé) et commenté.
. **P0 — vrais défauts** : cast `unchecked` (→ lecture typée / `safeCast`),
   `check for instance is always true/false` (assertion tautologique ou branche
   morte), API **dépréciée maison** (migrer les appelants puis **supprimer**
   l'overload si plus utilisé), `elvis always left`.
. **P1 — mécanique** : `!!` inutile, safe call inutile, `no cast needed`,
   variable/paramètre inutilisé, modificateur redondant.
. **P2 — déprécation tierce** : migrer **seulement** si petit et iso-comportement ;
   sinon consigner (raison + issue amont) et laisser.
. **Iso-comportement** : aucune API publique changée, aucun test affaibli ;
   les assertions tautologiques deviennent **plus fortes**, pas supprimées.
. **Preuve** = CI du borough (`Local = Build`) ; `compile*` + `ktlintCheck` en local.

== 4. Risques

[cols="2,4", options="header"]
|===
| Risque | Parade
| « Corriger » un warning en changeant le comportement | P0/P1 = iso-comportement strict ; toute sémantique touchée est documentée dans le rapport
| Suppression silencieuse | Interdiction `@Suppress`/`-nowarn` ; revue du diff
| Faux inventaire | `--rerun-tasks --no-build-cache` obligatoire
| Dérive Gradle API (`providers`) | Migration testée par la CI ; les mocks de test réalignés sur le type non-null
| P2 en masse | Consigné, jamais forcé : une US dédiée si un upgrade de lib est requis
|===
