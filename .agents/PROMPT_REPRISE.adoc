== Pièges à retenir (cumul)

1. *Version dérivée ≠ version publiée* : bumper le toml local d'un borough est
   OBLIGATOIRE pour qu'une release porte les changements (HTOWN S-218).
2. *Catch-22 D8 (anti-ghost)* : une entrée catalogue exige que l'artefact soit
   DÉJÀ publié Central — pour un artefact jamais publié, publier d'abord.
3. *Gardes épinglent les versions* — après CHAQUE bump toml, bump la garde dans le
   même commit.
4. *Contrats N0 = builds standalone* (pattern 0124) : pas de sous-projet, pas de
   `include(...)` — `./gradlew` dans le répertoire du contrat.
5. *nmcp collision* : ne jamais re-invoquer publishAggregationToCentralPortal sans
   vérifier repo1 d'abord.
6. *Polling repo1* : ~4-30 min après « deployment is publishing » (AUTOMATIC).
7. *La garde `PlatformCatalogAlignmentTest` n'est pas exécutée par la CI
   `runAllTests`* (agent-contracts = build standalone).
