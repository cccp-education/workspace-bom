== Pièges (cumul)

. *Un gate qui ne peut pas échouer est un faux vert* (S-335, S-338) : la dernière
   commande d'un `run: |` décide — `errexit` obligatoire dès 2 commandes.
. *Version dérivée ≠ version publiée* ; garde de version bumpée dans le **même**
   commit. `check` inclut ktlint. *Contrats N0 = builds standalone* (pattern 0124).
. *Catalogue Gradle* : un plugin inclus depuis la **racine** utilise le catalogue
   **racine**.
. *Local = Build, Tests = CI* ; une CI concurrente (autre dépôt) fausse le
   wall-clock — vérifier les `startedAt`.
. *ktlint* : `include(...)`/`setSource(...)` sont ignorés par ktlint-gradle ;
   `ktlintFormat` n'est sûr que si `git status` = exactement les fichiers signalés.
. *Warnings* : `-q` les masque ; `--rerun-tasks` seul restaure le build cache →
   `--rerun-tasks --no-build-cache`.
. *Toolchain* : `jvmToolchain(25)` (jamais `VERSION_25.ordinal` = 24) ; foojay 0.10.0.
. *Gardes qui nomment un motif interdit* : elles se **détectent elles-mêmes** →
   composer les littéraux.
. *Un runner Cucumber non enregistré est un test fantôme* (il compile, il ne
   s'exécute jamais) — vérifier `tasks --all` + `--dry-run check`.
. *`run: >`* = scalaire replié (une commande), pas un bloc ; *un `echo` final après
   un gate* est un rapport, pas une preuve — le retirer ou activer `errexit`.
