   commit. `check` inclut ktlint. *Contrats N0 = builds standalone* (pattern 0124).
. *Catalogue Gradle* : un plugin inclus depuis la **racine** utilise le catalogue
   **racine**.
. *Local = Build, Tests = CI* ; une CI concurrente (autre dépôt) fausse le
   wall-clock — vérifier les `startedAt`.
. *Warnings* : `-q` les masque ; `--rerun-tasks` seul restaure le build cache →
   `--rerun-tasks --no-build-cache`. Un `@Suppress` préexistant = warning caché.
   Mesure avant/après : `git worktree add` sur le commit parent (zéro pollution).
. *Cache GitHub scopé au dépôt* ; `setup-gradle cache-disabled` ; clé avec
   `github.job` ; arrêter Ollama + `chown` avant le post-step.

   `ktlintFormat` n'est sûr que si tous les autres fichiers sont conformes.
