== Pièges (cumul)

. *Un gate qui ne peut pas échouer est un faux vert* (S-335, S-338, S-339) : la
   dernière commande d'un `run: |` décide — `errexit` obligatoire dès 2 commandes.
. *`cmd | grep -q` sous `pipefail`* = faux rouge (SIGPIPE 141) → rediriger
   (`> "$RUNNER_TEMP/f"`) puis `grep -q f` (leçon S-318 rejouée en S-339).
. *Workflow-only* : `capsule` met `.github/**` en `paths-ignore` → valider par
   `gh workflow run <wf>.yml --ref main` (les autres dépôts déclenchent au push).
   Un `.github/` peut être **gitignoré** (`edster` : seul `__codebase__` est tracké).
. *Version dérivée ≠ version publiée* ; garde bumpée dans le **même** commit. `check`
   inclut ktlint. *Contrats N0 = builds standalone* (pattern 0124). *Catalogue Gradle* :
   un plugin inclus depuis la **racine** utilise le catalogue **racine**.
. *Local = Build, Tests = CI* ; une CI concurrente (autre dépôt) fausse le
   wall-clock — vérifier les `startedAt`. **Arbre partagé** : `git add -A` embarque
   les éditions en vol d'une autre session → stager des **chemins explicites**.
. *Warnings* : `-q` les masque ; `--rerun-tasks` seul restaure le build cache →
   `--rerun-tasks --no-build-cache`. *Toolchain* : `jvmToolchain(25)` ; foojay 0.10.0.
. *Gardes qui nomment un motif interdit* : elles se **détectent elles-mêmes** →
   composer les littéraux (vaut aussi pour un **commentaire** YAML, S-339).
. *Un runner Cucumber non enregistré est un test fantôme* — vérifier
   `tasks --all` + `--dry-run check`. *`run: >`* = scalaire replié, pas un bloc.
